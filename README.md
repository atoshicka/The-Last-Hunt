# The Last Hunt
Tower defense про охоту на монстров.
Расставляйте охотников по полю и продумывайте стратегию, чтобы истребить нечисть.

## Статус
В разработке время от времени - новые уровни и персонажи появляются по мере вдохновения.

## Стек
- HTML
- CSS
- JavaScript

## Инструменты
- Piskel - все спрайты
